# первая бета версия приложения, поэтому многое надо еще доделывать, однако основной функционал работает

# перед запуском
если хотите протестировать квиз с телефона, то раздайте сеть с телефона, и подключитесь с компьютера/ноутбука
если хотите протестировать квиз с компьютера, не надо ничего раздавать

# запуск
запустите ahora.exe
для теста с телефона просто просканируте и перейдите по qr-коду
для теста с компьютера (на котором и запущено приложение) перейдите по http://127.0.0.1:8080 в браузере

# квиз
из браузера на телефоне или на компьютере присоединитесь как команда, дальше квиз
с компьютера перейдите на панель админа, и там можно регулировать и оценивать результаты квиза
для изменения врмени таймера нажмите правой кнопкой мыши по нему, для начала/остановки - левой
